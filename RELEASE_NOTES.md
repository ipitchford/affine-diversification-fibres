# Release notes: 0.3.0-candidate-r2

This is an additive, explicitly unrefereed successor to candidate 0.2.1. It is archived under version DOI `10.5281/zenodo.22041054` in concept lineage `10.5281/zenodo.21851318`.

The principal addition is a finite-sample signal-to-decision workflow for one exact fixed-stem reconstructed tree under the declared homogeneous time-varying birth-death law. Exact geometric tip-count inversion and a conditional DKW--Massart band yield a simultaneous set for the pulled scale `F`; the package propagates that set through the affine fibre to three-valued target decisions.

The frozen CRABS comparison remains supporting evidence. It found endpoint deficits in all 240 returned primary clouds plus 60 structural censors, but exact certification changed only 532 of 3,840 clustered statuses (13.854%). The prespecified H4 utility gate therefore failed. This release does not claim that the method is a must-have, an essential complement to CRABS, empirically validated, independently reproduced, formally verified or peer reviewed.

Producer-side replay passed on the qualified macOS environment and in public GitHub Actions run 32457758437, including the pinned Linux-container smoke job. External process-theory review, unaffiliated reproduction and independent rights review remain not established.
