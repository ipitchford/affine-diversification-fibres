- `manuscript.md` — accessible text companion.
- `STATUS.md` / `STATUS.json` — safe claim, release state and open gates.

- `LICENSE.md` and `LICENSE_MAP.json` — CC0 prose/data, MIT code and upstream exceptions.
- `verification/verify_route_a_candidate.py` — integrated producer-side verifier.
- `docs/final_integrity_report_20260821.md` — Stage 4.5 decision.
